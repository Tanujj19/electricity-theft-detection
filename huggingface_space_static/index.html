🔧 Architecture

End-to-End ML Pipeline

🗂️
Stage 1
Preprocessing
ffill/bfill imputation, duplicate removal, 99th percentile outlier capping.
⚙️
Stage 2
Feature Engineering
12 statistical features: CV, load factor, sudden changes, rolling stats, weekend ratio.
📊
Stage 3
EDA + SMOTE
16 visualizations incl. PCA + t-SNE. SMOTE applied to fix 95:5 imbalance.
🤖
Stage 4–5
Training + Optuna
Baseline: LR, RF, XGBoost via GridSearchCV. Advanced: LightGBM, CatBoost, XGBoost via Optuna (30 trials).
📈
Stage 6
Evaluation
Threshold tuning, error analysis (FPR/FNR), benchmark vs published literature.
🔍
Stage 7
SHAP XAI
Global feature importance, beeswarm summary, per-consumer waterfall explanations.
